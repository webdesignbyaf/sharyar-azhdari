# S-ART / Sharyar Azhdari

## Kurzprofil
- Marke: Kunst- und Kultur-Galerie S-ART, Essen; Künstler Sharyar Azhdari.
- Ziel: eigenständige, ausdrucksstarke Pop-Art-Website für Kunstinteressierte und Sammler.
- Sprache: Deutsch; einzelne kurze englische Kunst-Statements.
- Referenzen: https://s-art.work/ für Inhalte und Originalwerke; https://www.noartmusic.com/ für Präsenz und Bewegung.
- Gestaltung: animierte Graffiti-Collage, Road Rage/Marker-Typografie, Schwarz, Pink, Cyan und Gelb. Keine künstlich nachgebauten Kunstwerke oder dekorativen SVGs.

## Gezielt bearbeiten
- Inhalte: `index.html`.
- Gestaltung: `styles.css`.
- Verhalten und Werkdaten: `app.js`.
- Assets: `assets/images/`, `assets/fonts/`; Herkunft: `assets/sources.json`.
- Start: `npm run dev`, http://127.0.0.1:4178.
- Prüfung: `npm run check`; Ausgabe: `npm run build`; Uploadpaket: `npm run export`.
- Details, Quellen und GitHub-Anleitung: `README.md`.
